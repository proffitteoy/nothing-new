# 论文库与 TDA 周报

`/papers` 只保留「TDA 周报」「读过的论文」两个视图，默认打开周报。顶部旧标题、介绍与统计区已删除；页面与图谱背景透明，透出既有站点背景，不再包裹大块白色卡片。内容下方使用 75% 的边缘渐隐白色阅读遮罩，不模糊背景；辅助文字采用较深颜色，避免和背景混在一起。周报左侧选择期数，右侧阅读目录；已读视图以 Zotero 文件夹关系图、层级目录及文件夹内论文列表共同组织内容。搜索支持标题、作者、DOI、arXiv ID。点击论文打开详情，直接展示原文信息、已关联公开笔记与周报评价。内页导航和手机导航均有「论文」入口；首页论文标签与封面预览均直达完整论文库，默认显示周报，不再先打开旧周报弹窗。

论文页根元素使用 `main.page` 匹配，优先于共享 `PaperMonitor` 的 `.panel`，避免样式加载顺序改变时恢复实色底板、边框和圆角。手机断点使用相同优先级，保留原有尺寸规则。遮罩位于页面内第 0 层，目录内容位于第 1 层；遮罩不拦截点击。

周报先请求最新一期并立即展示，再加载完整往期目录；加载期间不先显示旧的构建快照。最新一期读取失败时才回退到已保存周报，往期加载失败不会清掉已显示的最新一期。

## 数据归属

| 数据                               | 维护位置                                     | 网站获取方式                                                             |
| ---------------------------------- | -------------------------------------------- | ------------------------------------------------------------------------ |
| 标题、作者、年份、DOI、arXiv、摘要 | Zotero Desktop                               | 本地单向同步                                                             |
| 分类                               | 获批的 Zotero Collections                    | 本地同步，保留子文件夹分类                                               |
| 已读／阅读中                       | Zotero 的 `paper:read`／`paper:reading` 标签 | 本地同步；已读优先                                                       |
| 公开笔记                           | Obsidian → `content/` → Quartz               | 从公开构建产物建立关联                                                   |
| 周报原文与评价                     | 原监控仓库                                   | `POST /api/papers` 上传；Cloudflare 使用内容 KV，旧 Vercel 使用私有 Blob |
| 「阅读笔记」「周报收录」标识       | 系统计算                                     | 与阅读状态独立                                                           |

无阅读标签时不显示状态，不推断「未读」。有笔记、被周报收录均不推断已读。不提供网页修改阅读状态的后台，日常索引同步仍然只读 Zotero，也不为论文重复保存笔记正文。本轮根据作者明确要求，通过 Zotero 10 本地 API 为当时的 181 条现有书目一次性追加 `paper:read`，保留原标签并逐项验证；一次性操作不纳入日常同步，以后只需运行索引更新。第一版不公开 Zotero Child Notes、批注、附件、私人标签或「存在私人笔记」的信息。

## Zotero 同步

本地 Zotero 须运行并开启本地 API（设置 → 高级 → 允许此计算机上的其他应用程序与 Zotero 通信）。默认只读取 `http://127.0.0.1:23119/api/users/0/`，不需要云端 API Key，也不在网站服务端连接作者电脑。

```powershell
npm.cmd run sync:zotero:dry
npm.cmd run sync:zotero
npm.cmd run sync:zotero:check
```

- `dry`：读取元数据、预览变化，不写快照或审阅决定。
- `sync:zotero`：写入有变化的 `data/paper-library.json`；无变化时保留原同步时间。原子替换成功才更新快照。
- `check`：不写文件；存在变化时退出码为 1，读取失败也以非零退出。

2026-11-23，作者明确批准以下十个顶层 Collection **及其全部子文件夹**同步公开元数据：2026 第三届大湾区拓扑会议、拉普拉斯算子、拓扑优化、拓扑杂文、投影算子、谣言的拓扑分析、杂文、Cesàro 算子、Hyperbolic knot、tda+量化。批准键写在 `zotero-sync.config.mjs`；此后这些范围内新增书目自动同步。`includeUnfiled: true` 同时索引没有有效文件夹归属的书目，显示为「未分类」；有效但未批准的 Collection 不会因此被公开。快照保留 `collections[].parentId`，空文件夹也保留在目录中。新增顶层文件夹仍须明确加入配置。新增子文件夹继承已批准的 `includeChildren: true`。

配置使用稳定的 Collection Key，重命名无需重新授权。`includeChildren: false` 仅同步该文件夹直接包含的条目。`exclude` 按完整 Zotero 标识排除单篇论文，优先于所有批准决定：

```js
exclude: ["zotero:personal:ABCD2345"]
```

如需改为逐篇批准，设置 `reviewMode: "items"`，运行 `npm.cmd run sync:zotero:review`，输入 `y/n/s/q`。`y` 一次批准后续自动更新，`n` 排除，`s` 暂跳过，`q` 结束本轮。决定存于 Git 忽略的 `.sync/zotero-sync-decisions.json`；需要跨机器保存的明确批准可写入配置的 `approvedItems`。非交互终端不能运行审阅。审阅不会修改 Zotero。

API 不可用、分页未读完整、批准的文件夹不存在或返回格式错误时，脚本报错并保留最后成功的快照；正常空结果也不能直接覆盖非空快照。确需清空时，检查 `--dry-run` 的结果后显式执行 `npm.cmd run sync:zotero -- --allow-empty`。未批准任何文件夹始终报错，不视为空库同步成功。

脚本查询获批 Collection 的顶层条目；启用未分类入口时，额外读取个人库顶层列表，只导出没有有效 Collection 归属的书目。过滤 note、attachment、annotation，按字段白名单导出；不请求 Child Notes、附件文件地址或全文。分页读取失败不会发布部分结果。不会写入 `E:/math`、Zotero 数据库、云端 Blob 或 Git 状态。

`data/paper-library.json` 是供代码审阅和构建使用的公开书目快照：同步后需随站点构建／部署才会更新网站。周报仍走原动态上传链路，不需要每周部署。Cloudflare 的 `SITE_CONTENT` 绑定承载周报原文，生产与 Preview 隔离，独立于适配器缓存；未绑定时保留 Vercel Blob 路径。`npm run build` 不会自行连接 Zotero 或运行 Obsidian 发布审阅。

## 笔记关联：无需改写已有笔记

系统只读取 Quartz 清单中真实存在的公开文章，不扫描私人 Vault。公开笔记里的 Zotero 文献链接、arXiv 原文链接或 DOI 链接会自动建立关联；不按相似标题猜测。个人库链接示例：

```text
zotero://select/library/items/ABCD2345
https://www.zotero.org/users/20148006/items/ABCD2345
https://arxiv.org/abs/2401.12345v2
https://doi.org/10.1234/example
```

网页 Zotero 链接按真实用户／群组 ID 隔离；相同 Item Key 出现在其他库中不会误匹配。`personal` 对应本地 `users/0` 的实际个人库。DOI 不区分大小写，arXiv 不区分版本号；新旧格式 arXiv ID 均支持。

无法自动识别或不想在正文放链接时，编辑 `data/paper-note-links.json`，值为相对 `content/` 的原始 Markdown 路径：

```json
{
  "zotero:personal:ABCD2345": ["math/某篇阅读笔记.md"],
  "doi:10.1234/example": ["misc/某篇随想.md"]
}
```

只有路径实际对应公开构建产物才产生笔记标识；映射本身不会发布私人笔记。取消发布笔记并重新构建后，论文页上的关联随之消失。一篇笔记可关联多篇论文，一篇论文也可关联多篇笔记。

也支持可选 Frontmatter：

```yaml
---
paper_refs:
  - zotero:personal:ABCD2345
  - arxiv:2401.12345
---
```

Quartz 将此字段保留到文章产物。现有杂谈同步会保留博客目标文件 Frontmatter，因此对已发布杂谈，推荐正文链接或独立映射，避免只在 Obsidian 源 Frontmatter 修改后未生效。

论文详情直接展示关联笔记的标题、更新时间和 Quartz 已渲染正文，复用已有公式、图片与内部链接，不另建 Markdown 渲染管线。点击笔记标题会在新标签页打开原 `/blog/...` 或 `/chatter/...` 页面使用目录和反向链接，当前预览保留。不提供独立的「阅读笔记」视图；只有已经公开且具有关联标识或映射的笔记正文会传给论文页。没有公开关联时，不显示笔记区域，也不展示私人笔记数量。

论文摘要在服务端复用 `lib/papers.ts` 的周报 Markdown／KaTeX 渲染链，详情沿用周报正文样式，支持公式、强调、列表和链接。公开快照保留原摘要文本，浏览器只接收已渲染 HTML，不额外加载解析器。论文预览、周报导读及首页周报中的正文链接统一在新标签页打开，并设置 `noopener noreferrer`；笔记中的页内锚点继续在当前预览中定位。

### 导入文本的清洗规则

渲染前先经过同一处 `normalizePaperMarkdown`，摘要与动态上传的周报均使用此入口。规则取自真实摘要和 2026-11-09、11-16、11-23 周报，不改写书目快照或上传原文：

| 输入问题                                                  | 处理                                                                             |
| --------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `https://arxiv.org/abs/2611.09610；**HTML 全文：**`       | 为裸网址加显式边界，中文标点与加粗字段留在链接之外，避免生成错误的原文标识和地址 |
| `(d\leq2)`、`(mathbb F_2)`、`(gamma)`、`SW_1`             | 识别具有数学特征的表达式，补齐已知命令和美元定界符；转换前用 KaTeX 验证语法      |
| `(B^nG\simeq K(G,n))`、`([a,b))`                          | 按嵌套括号提取完整表达式，保留内部函数及半开区间                                 |
| `\(...\)`、`\[...\]`、导入器遗留的反斜杠包裹表达式        | 统一为现有渲染器支持的行内／独立公式；处理已核对的 `øverline` 命令损坏           |
| `\emph{persistent Laplacian}`、`Fr{é}chet`、`w.r.t.\ the` | 转成对应的 Markdown 强调、正常字符与空格                                         |
| PDF 文本中的中文软换行                                    | 合并相邻汉字之间的单行换行，保留空行分段                                         |

代码围栏、行内代码、已有美元公式、原始 HTML、引用定义及显式链接的地址均按原始位置保护，不对其做全局替换。普通括注和罗马数字列表编号保留。无法确定的断词、未知 TeX 命令及已被压成纯文本的 MathML 不推测还原；例如 `∑n=0∞` 缺少原始上下标结构，应修正来源后重新同步。已有 Quartz 笔记 HTML 不重新解析为 Markdown。

## 周报与合并

`GET/POST /api/papers` 的请求格式、认证、Blob 路径和动态刷新保持兼容。论文库以 DOI／arXiv 等明确标识合并书目，优先使用 Zotero 元数据；同一论文多次入选仍保留全部期数与评价。没有可靠标识的条目独立展示，不按同名合并。周报视图保留源报告的论文顺序、导读与综合判断。

页面进入时检查最新周报；更新失败时保留已有内容并显示提示。已经打开的论文预览保存打开时的报告版本，后台修订不会替换正在阅读的正文。关闭后再打开即可读取更新版本。

## PDF 发布保护

Obsidian 笔记获准公开，不代表它引用的论文 PDF 也获准公开。同步脚本对 **所有 PDF** 默认跳过，包括被 include/glob 直接选中的 PDF；图片仍沿用现有流程。PDF 已确认有公开授权并决定发布后，才将其相对 Vault 根目录的精确路径写入 `obsidian-sync.config.mjs` 的 `publicPdfFiles`：

```js
publicPdfFiles: ["论文附件/已获公开授权的论文.pdf"]
```

该列表只解除 PDF 限制，不自动加入发布范围，exclude 仍有效。未公开 PDF 的本地引用可能无法在网页打开，推荐改为论文公开原文链接。此变更不扫描或删除历史非托管附件；如需清理已有公开 PDF，另行盘点再处理。

## 周报首屏与预加载

`/papers` 首屏由服务端准备已发布的最新一期，使用按 Blob Store 隔离的 60 秒数据缓存与 ISR；无需等浏览器接口返回。较旧的本地种子只用于无配置、无快照或读取失败时的回退。读取失败不进入数据缓存，浏览器会立即重试。首屏传递获取时间，客户端复用剩余有效期，避免较旧请求或路由快照覆盖较新的报告。

保留最新一期优先：开场预热和首屏只获取最新一期，往期通过完整接口在后台加载。两种范围分别缓存 60 秒、共享各自并发请求，超时 12 秒；失败保留可读内容，下次进入重试。手动选期、正在阅读的正文、现有遮罩和图谱保持原行为。

上传成功后失效论文页和周报数据缓存，在 Next `after()` 中主动获取同源 `/papers`，预热实际 HTML 与 RSC 上下文的数据缓存。预热失败只记录日志，不撤销上传。首页继续使用现有论文入口，新开场预取路由并并行准备最新一期；直接进入论文页不等待其他页面资源。

本地验收使用隔离周报数据：禁用 JavaScript、阻断浏览器接口时首屏已有当前期；模拟发布并完成预热后，禁止后续 Blob 读取，首位访客仍读取新版本。未向真实 Blob 写入报告，真实移动 Safari 与线上 CDN 尚未验收。
