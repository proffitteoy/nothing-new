# 生产图片加载策略

网站保留浏览器 native 网络调度、Next Image 与 Cloudflare Images / CDN 缓存链路，不使用自定义下载队列、分层 residual 或客户端解码器。公开图片来自构建静态资源，番剧镜像来自 Cloudflare 内容存储；历史研究可从 Git 历史恢复。

## Cloudflare 动态封面（2026-11-27）

OpenNext 对 `/_next/image` 的相对源默认读取 `ASSETS`，而 `/anime/blob/covers/**` 是动态路由，不能按静态文件读取。Worker 仅在优化请求内适配 `ASSETS.fetch`：同源番剧封面及旧 `/assets/**` 经当前部署的 `ctx.exports` 读取，源路由仍使用真实静态绑定并保留原有路径校验。其余静态图片维持原读取方式，避免跨域回源及自递归。

番剧封面优化失败后尝试同源镜像原图，原图也失败才显示占位；更换封面 URL 会恢复优化。首屏预算与懒加载规则保持不变。发布验收要检查实际优化响应和滚动后的图片解码，不能仅以原图 200 判定成功。

## 列表图片

- 番剧首批立即加载预算：移动端 4、桌面端 6，Save-Data / 2G 为 2。杂谈为 2，受限网络为 1。
- 其余图片仅在进入扩展视口后挂载：移动端 256 px、桌面端 320 px，受限网络为 0。
- 已挂载图片不会因离开视口、改变窗口大小或切换锚点而卸载。不支持 IntersectionObserver 时异步显示图片，番剧仍可手动继续展开。
- 番剧通过 `aspect-[3/4]` 预留空间；`#watched` 直达在快照挂载后定位，并把立即加载预算分配给已看区域。
- 杂谈保持自然封面比例、移动两栏和桌面三栏。站内及已允许的文件夹封面走 `Image fill + sizes`；未知第三方保持原始 URL、lazy、async 和 no-referrer。
- 杂谈首张内容图保持正常优先级，其余立即加载内容图使用低 fetch priority，避免增加图片 preload。过滤后线性计算图片序号，避免逐卡片重复扫描此前所有条目。

## 音乐与其他图片

- 网易云当前封面统一为 `256y256`，非当前队列封面为 `128y128`。DOM 封面与 WebGL 纹理保持兼容的 CORS 请求模式。
- 首页和音乐页不渲染不可见的浮动播放器视图，播放状态仍由 MusicProvider 保留。
- 保留 Quartz 正文响应式图片、第三方友链原 URL 和固定尺寸属性。
- 背景/头像/关于页主视觉保留现有 Next Image 规格、站内 URL、Blob 路径和快照 schema。两阶段开场与必要资源预热见 [全站启动与导航](site-startup.md)。

## 格式与缓存

继续使用 Next Image 的 WebP 协商及现有尺寸、质量和缓存配置。没有部署全量预生成、第三方镜像或自定义格式；也不以实验结果宣称生产 LCP 已提升。

## 维护验证

修改生产图片链路后执行完整测试、TypeScript、定向 ESLint、格式检查和 `git diff --check`。无上传副作用的构建使用：

```powershell
npm.cmd run build
npm.cmd run cf:build -- --skipNextBuild
```

构建不上传图片或写入远端数据。旧 `images:*` Blob 上传命令已退役。Workers Builds 设置 `WORKERS_CI` 后会自动在 `postbuild` 打包 OpenNext；本地分步构建使用上述两个命令。

当前项目与 Cloudflare 构建使用 Node 22。浏览器回归关注近视口挂载、锚点跳转、加载失败、图片比例和 preload 数量；本地回归不等同于部署后的冷缓存性能采样。

### 2026-09-22 收尾验证

- 完整测试 59 项通过，包含 immediate 图片服务端输出及 deferred 图片不提前暴露 URL；TypeScript、修改文件 ESLint、Prettier、生产构建和差异检查通过。
- 本地生产构建的杂谈页面：390×844 挂载/成功加载 14 张内容图，1440×900 为 9 张；两者扩展视口下方未挂载图片，图片 preload 均为 2，实验全局变量不存在。截图确认两栏/三栏和自然比例保持。
- 使用仅注入独立浏览器会话的 40 项番剧测试快照：异步直达 `#watched` 正确定位，立即加载预算为已看 4、正在看 0；切换两次锚点后，已挂载图片仍保持连接且无坏图。此项验证的是客户端逻辑，不是线上快照或请求量基准。
- `images:dry` 只读盘点 81 张本地图片。因无本地 Blob 凭据，未执行远端一致性检查或上传；没有重新采样线上 LCP，也没有声称线上提速。
