# 蓝色基调与组件色卡

2026-11-07。蓝色承担站点识别与主要操作，阅读面使用中性白和深灰蓝；玫红、紫色、青绿按组件和状态分配。界面禁止米黄、奶油白、暖灰纸张和浅琥珀底色。布局、内容与交互沿用既有实现。

## 素材与构建

图片、视频、代码块、首页画布、开场 iframe、三维画布及预览图没有统一去色／染色滤镜。源图片、模型、纹理和正文均未改写。素材中的自然颜色不靠全站像素阈值处理；检查对象是各组件定义的界面色值与状态。

Quartz 的独立构建色卡位于 `quartz.config.ts`。修改后运行 `npm run notes:build`，不直接编辑生成的 `public/quartz-assets/note.css`。显示菜单组件目前未挂载，其保留样式仍继承这套色板。

## 验证边界

逐组件检查桌面／手机、日间／夜间、悬停／焦点、弹窗及错误状态，检查背景、文字、边框和状态是否仍有米黄定义，以及图片、场景和代码是否保持原色。视觉检查不以“整张截图只剩冷色像素”作为通过条件。此前单色版本的截图与检测记录不适用于本版本。

本版本生产构建与类型检查通过，90 项现有测试通过，lint 无错误（3 条既有警告），Prettier 与差异检查通过。Chromium 覆盖 1440px／390px 的 60 个页面和组件状态：界面背景／边框扫描无米黄发现，所有所检图片、画布和代码块的 CSS 滤镜均为 none，无横向溢出或未捕获脚本异常。证据位于忽略目录 `.sync/tmp-component-palette/`。

音乐和番剧使用明确标记的本地数据夹具验证操作与状态色，不代表线上服务可用性；未部署生产，也未完成真实移动 Safari 验收。组件渲染和交互检查不等于用户已认可美术效果。
