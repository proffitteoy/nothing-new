# 窗棂与公式 · Window & Formula — 全站色彩规范

**更新：2026-11-19。** 本文的「当前规范」覆盖此前的冷蓝纯白色板；下方带有 2026-11-16、2026-11-13、2026-11-07 日期的测试记录仅作历史验证记录，不表示新方案已经通过相同测试。

## 设计边界

站点的观景窗、三维书桌、山湖日景、二次元插画、番剧封面与杂谈封面保留素材原色。首页的场景构图、窗洞材质和谱场作用规则遵循 [v2 观景窗规范](Nothing_New_首页重构_设计与开发规范_v2_2026-11-17.md) 与 [当前首页说明](home-scene.md)；不要拿页面 Token 为整个场景上色。木色（参考 #9C6F44）属于三维材质，不进入全局交互状态色。

界面固定为浅色，不增加夜间切换。页面底色选择冷中性浅灰蓝，与木材和图像的暖色保持对照；不使用全局宣纸米黄、奶油白或暖灰纸层。以颜色承担信息语义，而不是每条信息都加卡片。

## 核心 Design Tokens

| 角色 | Token / 实现 | 色值 | 约束 |
| --- | --- | --- | --- |
| 页面基底 | `--site-bg` | `#F2F5FA` | 冷中性底色；已有插画背景不能被整体覆盖 |
| 文字承载面 | `--site-surface` | `#EEF2F6` | 用于必要的长文、目录和工具面板，不是通用卡片 |
| 凹面／输入 | `--site-recess` | `#E4EBF2` | 输入槽和缺省占位 |
| 边界 | `--site-line` | `#CED7E0` | 轻分隔；开放排版优先 |
| 正文 | `--site-ink` | `#1E2226` | 标题、正文与公式 |
| 辅助文字 | `--site-muted` | `#5C646D` | 日期与正文说明 |
| 深湖蓝 | `--site-accent` | `#1E5B73` | 主要导航、链接与数学结构强调 |
| 暮樱粉 | `--site-pink` | `#C85A7C` | 仅供装饰图形、较大图标与非正文重点 |
| 深樱红 | `--site-detail` | `#913450` | 供小字号文字使用的樱粉深色对应 |
| 紫色 | `--site-violet` | `#6A5882` | 少量既有组件的辅助语义 |
| 青绿 | `--site-mint` | `#26714F` | 成功、已完成等语义状态 |
| 局部透层 | `--site-glass` | `rgb(242 245 250 / 94%)` | 仅用于内容必须有稳定底色的位置 |
| 背景保护层 | `--site-wash` | `rgb(242 245 250 / 10%)` | 轻度保护插画，不作全屏强模糊与整体调色 |

颜色由 `app/globals.css` 维护，Tailwind 的 `blue`、`rose`、`violet`、`teal` 色阶同步；`quartz.config.ts` 负责数学笔记生成样式的对应 Token。不要直接手动修改构建产出的 `public/quartz-assets/note.css`。

## 语义与可读性

- **信息／定义／定理／引理**：使用深湖蓝 `#1E5B73` 和局部淡蓝 `#DEEDF2`；证明、反例是数学内容类型，不应无条件等同系统的成功/危险状态。
- **完成／成功**：用深绿 `#26714F`，必要时配 `#E6F3EC`。
- **错误**：用深樱红 `#913450` 或其他对比度足够的语义深色；`#C85A7C` 不能作为浅底上的普通小字颜色。
- **注意／警告**：只有真正的状态警告才使用警告色，不能把所有反例与证明中的边界条件涂成警告卡片。
- 在 `#EEF2F6` 背景上，正文 `#1E2226`、辅助文字 `#5C646D`、主蓝 `#1E5B73` 的计算对比度分别约为 14.23:1、5.34:1、6.67:1；装饰樱粉 `#C85A7C` 只有约 3.58:1，不用于普通小字。
- 透明承载层和封面叠字的对比度需以最终合成画面为准，普通文字至少 4.5:1，非文本关键图标／焦点至少 3:1；这些静态比值不能代替实图检查。

## 逐页面使用规则

| 页面 | 处理方式 |
| --- | --- |
| 首页／项目小屋 | 原色日景、木质窗洞、模型和书桌保留本来的颜色；主交互采用深湖蓝，不给整个场景加灰蓝滤镜，不把木色当全站按钮色 |
| 番剧 | 番名、分组评分和封面评分直接排版，不恢复白色胶囊／卡片；封面原色不变；缺省图像和加载态允许使用中性槽色 |
| 杂谈 | 保留不规则封面与开放排版，搜索区域可使用克制的局部稳定底色；封面下沿局部暗渐变用于保障标题与日期可读性，不添加整页 78%–85% 不透明遮罩 |
| 数学笔记 | 长正文、目录与反向链接保留稳定阅读底色；数学结构以深湖蓝为主，公式与代码保持原内容及语法色；不为每个公式添加独立装饰卡片 |
| 关于 | 不恢复「工程身份」「研究身份」两个标题组件，也不恢复目录中的对应入口；正文可使用局部中性透层，避免多个纯白大框叠加 |
| 友链 | 头像、网页预览保持原色；交互与链接用深湖蓝，必要的加载面和卡片采用统一阅读色，不额外加装饰性的彩色边框 |
| 导航 | 中性浅底和深色正文，激活与焦点用深湖蓝；樱粉仅限装饰细节，移动端导航保持操作和焦点可达性 |

## 不做的事情

不将 `#F5F3EE`、`#FCFBF9`、`#EAE6DF` 等暖纸色直接铺满全站；不把 `#9C6F44` 木色升级为全局 UI 变量；不把番剧标签换成粉色实体徽章；不使用高不透明度的整屏暖色蒙层；不新增夜间模式；不改背景原图或 3D 贴图；不靠叠加越来越多的玻璃卡片解决布局问题。

## 素材与构建

图片、视频、代码块、首页画布、开场 iframe、三维画布及预览图没有统一去色／染色滤镜。源图片、模型、纹理和正文均未改写。素材中的自然颜色不靠全站像素阈值处理；检查对象是各组件定义的界面色值与状态。

Quartz 的构建色卡位于 `quartz.config.ts`，仅输出固定浅色和 `github-light` 代码高亮。修改后运行 `npm run notes:build`，不直接编辑生成的 `public/quartz-assets/note.css`。旧夜间静态素材可作为历史设计源保留，不由前端加载。

## 验证边界

### 桌面文字与文案（2026-11-16）

本轮只整理访客界面的重复标签、常驻教程和技术错误详情。文章、笔记、关于页三份 Markdown、项目描述、友链介绍、周报、歌词、公式以及个人标题／副标题保留原文；修改前记录 252 个内容文件哈希，交付时逐一比对。移动端布局、导航和手势不在本轮改造与验收范围。

- 桌面常用操作和列表文字为 14–16px，日期、数量和标签为 12–13px；不对公式上下标应用界面字号下限。
- 目录卡片、关于页章节／索引、友链和局部工具栏使用稳定的中性阅读面。保留外围原画，不增加整页遮挡，不对图片和模型加滤镜。
- 杂谈封面标题区使用随文字高度扩展的局部暗色渐变，日期和类型使用浅色；不能继承浅色阅读面上的深色正文。
- 正常状态不常驻点击、滚动、悬停教程；项目操作说明折叠保留。失败、加载、复制和空结果仅在相应状态反馈，保留重试、键盘操作和可访问名称。
- 普通文字对比度目标至少 4.5:1，功能图标／焦点至少 3:1。透明面需按最终合成背景检查，装饰细线与数学字号单独处理。

目录自动摘要从构建后的首个正文段落生成可选 `NoteArtifact.descriptionHtml`，紧邻显示公式保留完整节点，复用现有 KaTeX 样式。仅对摘要副本移除链接包装、重复 ID 和交互元素，正文树不变。显式作者摘要与旧产物继续使用原有纯文本 `description`，无需迁移或浏览器端 Markdown 解析。

本地证据位于忽略目录 `.sync/tmp-readability-20261115/`，包含改前／改后截图、作者内容基线及桌面检查报告。番剧正常态使用正式站公开真实快照在本地新版页面渲染；只有错误状态使用临时失败夹具，夹具不写入公开导航预览。验收结果见该目录报告；不代表生产部署或移动设备验收。

本轮验证：Node 22.23.5 下 123 项测试、完整生产构建（247 页）通过；类型检查通过，ESLint 0 错误、3 条既有警告。生产 Chromium 覆盖 1024／1280／1440／1920px 共 48 个页面与交互状态，未捕获页面异常为 0；另通过原有桌面杂谈搜索、长标题、封面失败和跳转检查。252 个受保护内容文件哈希全部一致。六张导航预览由本地新版页面重新生成，番剧借用真实公开快照（284 条），不将其视为本地番剧数据服务恢复的证据。

逐组件检查桌面／手机、悬停／焦点、弹窗及错误状态；在白天、夜晚、系统深色偏好及旧主题缓存下均须保持相同界面。检查背景、文字、边框和状态是否仍有米黄定义，以及图片、场景和代码是否保持原色。视觉检查不以“整张截图只剩冷色像素”作为通过条件。
