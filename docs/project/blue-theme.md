# 全站蓝色色卡

2026-11-06 按用户最新要求统一全站：基色为蓝色，任何位置都不使用米黄色，包括奶油白、暖灰纸张、浅琥珀底色、渐变、边框和光晕。本规范覆盖旧视觉文档里的暖色 Token；既有内容、布局、导航、谱场几何及播放逻辑保持原有实现。

| 用途         | CSS 变量         | 日间      | 夜间      |
| ------------ | ---------------- | --------- | --------- |
| 页面底色     | `--site-bg`      | `#EDF5FF` | `#0B1628` |
| 阅读表面     | `--site-surface` | `#F4F8FF` | `#12243B` |
| 输入与凹面   | `--site-recess`  | `#E4EFFC` | `#0D1C30` |

全站变量在 `app/globals.css` 定义，组件原有局部变量只作别名，日夜切换继承根主题。Tailwind 状态与强调使用蓝色阶；贡献日历仍显示原始贡献数据，颜色改用蓝色深浅。提示信息保留文字与图标语义，移除琥珀底色。

笔记外壳、搜索目录、标签、正文、文本高亮、问题与警告 callout 同步去掉暖色，代码块也做冷蓝调色。Quartz 独立生成的日夜色卡在 `quartz.config.ts` 对齐；修改后必须重新运行 `npm run notes:build`，不要直接改生成的 `public/quartz-assets/note.css`。

图片、视频、首页画布、开场 iframe、三维小屋及其静态预览在呈现层使用同一冷蓝调色，消除原画、封面和烘焙贴图中的米黄与暖光。此处理会使彩色图片呈蓝色单色调；源图片、模型、纹理文件没有改写，也没有增加遮住原画的全页背景层。音乐预览夹具中的背景图同样冷色呈现。日月 SVG 与导航标记直接使用蓝色，首页谱场使用蓝／青蓝／钢蓝三组颜色，保留原来的轨迹与周期。

验证需覆盖七个入口的日夜主题、笔记正文和目录、首页音乐／周报弹窗、三维与静态小屋、窄屏。显示菜单组件目前未挂载，保留的样式也同步引用全站色卡。除类型、lint、测试与生产构建外，还需检查浏览器计算样式和实图；自动检查不能代替人工视觉认可。

本次本地验证：生产构建、类型检查、90 项现有测试、Prettier 与差异空白检查通过；lint 无错误，保留 3 条既有警告。Chromium 检查 28 个页面状态及 19 个展开态，覆盖 1440px／390px 日夜页面与 320px 手机圆盘；未发现横向溢出或未捕获脚本异常，所检截图的米黄像素检测计数均为 0。检测依据为暖色相、亮度与饱和度阈值，不代表穷举所有内容和浏览器。

证据位于忽略目录 `.sync/tmp-blue-theme/` 的 `report.json`、`interactions.json` 及同名截图。番剧实时接口本地不可用：真实页面检查覆盖加载／不可用状态，已看、在看及缺封面状态用明确标记的本地数据夹具验证，不作为线上接口可用性的证据。未进行生产部署。
