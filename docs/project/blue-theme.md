# 蓝色基调与组件色卡

2026-11-13。每页只维护一套固定外观：首页保留现有深色谱场及局部色卡，内页保留默认浅色。蓝色承担站点识别与主要操作，阅读面使用中性白；玫红、紫色、青绿按组件和状态分配。界面禁止米黄、奶油白、暖灰纸张和浅琥珀底色。保留当前布局、素材与业务交互。

没有日夜切换、按时段自动换色、系统配色跟随或隐藏入口；旧 `blog-theme` / `blog-theme-override-until` 缓存不再读取。根布局不挂载 ThemeProvider，各页面不保留暗色样式分支，项目小屋仅加载 GLB 内嵌的窗光贴图，笔记及代码高亮仅生成浅色版本。历史文档和截图中的日夜对照不再是当前功能要求。

## 内页固定色板

| 用途       | 变量             | 固定色值  |
| ---------- | ---------------- | --------- |
| 页面底色   | `--site-bg`      | `#F2F5FA` |
| 阅读表面   | `--site-surface` | `#FFFFFF` |
| 凹面／输入 | `--site-recess`  | `#EDF1F8` |
| 正文       | `--site-ink`     | `#29354B` |
| 辅助文字   | `--site-muted`   | `#627087` |
| 主蓝       | `--site-accent`  | `#4266CF` |
| 玫红       | `--site-detail`  | `#AD346C` |
| 紫色       | `--site-violet`  | `#805AC8` |
| 青绿       | `--site-mint`    | `#146D64` |
| 边框       | `--site-line`    | `#D8DFEB` |

色板在 `app/globals.css` 定义，同时提供 Tailwind 蓝／玫红／紫／青绿色阶。组件在自己的 CSS 或 JSX 中指定具体用途，不通过整站染色改变画面。

## 素材与构建

图片、视频、代码块、首页画布、开场 iframe、三维画布及预览图没有统一去色／染色滤镜。源图片、模型、纹理和正文均未改写。素材中的自然颜色不靠全站像素阈值处理；检查对象是各组件定义的界面色值与状态。

Quartz 的构建色卡位于 `quartz.config.ts`，仅输出固定浅色和 `github-light` 代码高亮。修改后运行 `npm run notes:build`，不直接编辑生成的 `public/quartz-assets/note.css`。旧夜间静态素材可作为历史设计源保留，不由前端加载。

## 验证边界

逐组件检查桌面／手机、悬停／焦点、弹窗及错误状态；在白天、夜晚、系统深色偏好及旧主题缓存下均须保持相同界面。检查背景、文字、边框和状态是否仍有米黄定义，以及图片、场景和代码是否保持原色。视觉检查不以“整张截图只剩冷色像素”作为通过条件。
