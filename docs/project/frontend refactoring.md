# 一、整体设计概念

## 1.1 我们到底要把网站设计成什么？

我不建议继续使用「研究室」作为整个网站的主概念。

因为你的项目页已经有真正的 3D 研究小屋，如果全站继续强调这种空间叙事，容易与项目页的现有特色重复。

我更希望最终网站给人一种感觉：

**打开的是一本精心设计的个人数字杂志，但这本杂志拥有传统纸质出版物不可能具备的数学图形、动画和交互。**

它应该同时具备以下三个层次。

| 层次   | 视觉特点              | 主要参考         |
| ---- | ----------------- | ------------ |
| 页面结构 | 精确排版、充分留白、清晰的信息层级 | Distill      |
| 交互系统 | 连续形变、精致反馈、富有趣味的细节 | Garden Eight |
| 视觉身份 | 数学生成图形、动画美术、柔和的色彩 | 独立设计         |

这个方案的关键，是把数学真正用于视觉结构。

页面的布局比例、生成图形和动效之间有相互联系。

但我们不能为了数学而数学。

文字仍然是主要内容，插画和动画提供情绪，数学结构负责建立可以持续使用的视觉身份。

# 二、全站视觉系统

这是整个改造最重要的一部分。

## 2.1 配色：从毛玻璃转向纸张与光影

你现在的网站主要采用紫蓝色、透明背景、大圆角和毛玻璃。

我建议保留紫蓝色作为个人识别色，但大幅减少毛玻璃的使用。

| 主要文字   | `#252936` | `#E9EAF0` |
| 次要文字   | `#747985` | `#A1A7B5` |

| 分割线    | `#DDDDE2` | `#343A48` |

这些是第一版设计候选值，最终必须根据真实页面截图调整。

我希望日间模式有纸张的质感，但不刻意模拟泛黄的古书。

夜间模式接近深蓝色的夜空，避免纯黑。

它可以作为页面的某一层视觉环境，通过遮罩、留白和局部透明度与文字区域融合。

**我们要减少大面积玻璃面板，增加开放式排版、清晰的图文关系和漂亮的背景构图。**

这样现代前端的设计感会更明显。

## 2.2 字体：学术气息的主要来源

我建议使用三套字体体系。

**第一套：界面字体。**

使用 Inter 搭配思源黑体。

主要用于导航、按钮、元信息、日期、系统状态和交互组件。

特点是清晰、现代、理性。

**第二套：文章与展示字体。**

中文继续保留思源宋体。

英文标题可以考虑 Newsreader 一类具有出版物气质的衬线字体。

主要用于个人介绍、数学笔记标题、研究内容以及较长的文章。

**第三套：数学字体。**

继续使用 KaTeX，但统一公式附近的字距、行距、编号和图表标题。

这里尤其值得借鉴 Distill。

它的设计指南明确区分正文、宽图、全页图和边注等不同版式，使正文和视觉材料能够自然组合。([Distill][1])

我希望你的网站也形成类似的布局规则。

例如，普通文章的正文宽度控制在约 720–760px，旁边允许出现边注和目录；较复杂的数学图形可以突破正文宽度，但仍然与文章网格对齐。

整个网站应当能看出严谨的排版设计。

# 三、数学视觉系统：贯穿全站的核心设计

这里我有一个非常明确的方案。

**直接从你已经实现的谱场系统出发，构建一套可用于导航、背景、过渡和栏目装饰的生成式视觉语言。**

我检查了：

* `components/field/spectralField.ts`
* `components/field/SpectralTracerLayer.tsx`
* `components/FieldScene.tsx`

你当前的实现已经具有比普通装饰性粒子动画更明确的数学基础。

其中，流线系统使用了由有限个模式构造的二维向量场，并采用了与

$$
V=J\nabla\psi
$$

相对应的结构。

这里

$$
J=
\begin{pmatrix}
0&1\\
-1&0
\end{pmatrix}.
$$

在连续模型下，这种向量场具有

$$
\nabla\cdot V=0
$$

的性质。

这意味着我们已经有了一个可以进一步发展的数学视觉系统。

## 3.1 设计一个统一的几何母题

我建议将它称为 **Field Motif**。

可以考虑一族随栏目变化的函数：

$$
\psi_i(x,y,t)
=
\sum_{k=1}^{m}
a_{ik}
\sin\left(
k_{x,k}x+k_{y,k}y+\omega_k t+\phi_{ik}
\right).
$$

其中，\(i\) 对应当前栏目。

每个栏目使用不同的参数组合，但共享同一种数学结构。

这样就可以得到八种彼此相关、又有明显区别的流线图形。

它们可以被用于：

* 首页的主要数学视觉。
* 顶部导航当前标签的标识。
* 栏目标题旁边的小型几何图案。
* 页面之间的连续形变。
* 文章封面或项目目录中的抽象装饰。

最重要的是，这些视觉对象来自同一套生成规则。

它们不会像分别找来的八张背景图那样割裂。

### 3.2 页面之间如何实现数学上的连续变化？

假设当前处于栏目 \(i\)，准备进入栏目 \(j\)。

我们可以对流函数进行插值：

$$
\psi_s=(1-s)\psi_i+s\psi_j,
\qquad s\in[0,1].
$$

相应的向量场为

$$
V_s=J\nabla\psi_s.
$$

这样，整个变化过程中仍然保持散度为零。

这就为页面切换提供了一种真正具有数学结构的连续动画。

当然，**视觉上不需要显示这些公式。**

普通访客看到的是漂亮、流畅、具有连续性的图形变换。

而感兴趣的人，可以在网站的相关介绍中了解它的数学构造。

我认为这种做法才真正符合你希望体现的数学巧思。

### 3.3 不同栏目怎样使用？

同一套数学系统，可以生成不同的视觉效果。

首页使用完整的动态流线。

项目页使用较粗的几何曲线作为信息面板的背景装饰。

音乐页可以让部分曲线参数受到音乐状态影响。

番剧页采用较柔和的静态线条，与封面插画形成联系。

笔记页只保留极少量的线条与几何图案。

这样既建立了全站统一性，也能保证数学文章不会受到大量动画干扰。

不过，这套系统不应该直接接管现有的 3D 项目场景或音乐粒子系统。

它首先承担全站视觉识别的角色。

# 四、导航标签：保留八个栏目，重新设计使用方式

这是你之前非常关心的问题。

我认为应该彻底保留目前的一级导航：

**首页｜项目｜音乐｜番剧｜杂谈｜笔记｜友链｜关于**

不改名，不合并，不增加新的一级栏目。

它们已经组成了比较完整的个人网站结构。

## 4.1 桌面端导航

我建议采用一种受到学术出版物目录启发的现代导航。

顶部保持固定，整体高度约 72px。

左侧是现有的网站标识：

**阿 の 宝藏之地**

中间是八个栏目。

右侧保留必要的全局操作。

导航不再使用明显的毛玻璃矩形。

改为接近纸张背景的半透明表面，底部有极细的分割线。

每个标签由三个部分构成：

**栏目名称、选中状态，以及简洁的交互反馈。**

例如当前处于「笔记」页面：

首页　项目　音乐　番剧　杂谈　**笔记**　友链　关于

「笔记」下方出现一条紫色细线。

这条线可以具有轻微的几何曲率，与前面讨论的 Field Motif 建立联系。

当切换到「项目」时，指示线连续移动到新的位置。

与此同时，页面顶部的小型数学图案逐渐变为项目页对应的形状。

这会让用户感觉是在同一个系统里移动。

### 4.2 悬停时的体验

这里可以借鉴 Garden Eight 的交互理念。

它们的设计团队强调动效应服务于注意力引导与使用体验，而不会阻碍页面操作。([Codrops][2])

我希望导航具有三个层次的反馈。

第一层，文字颜色发生轻微变化。

第二层，选中指示线向当前标签移动。

第三层，附近的几何线条产生短暂的形变。

第三层是视觉趣味，但不能影响实际点击。

动画也不应当让导航延迟响应。

我不建议给每个标签增加一个大面积预览弹窗。

因为你已经有八个栏目，如果每个导航项都弹出大型卡片，顶部会显得非常拥挤。

可以只在宽屏、鼠标悬停时出现一个很小的辅助提示，甚至完全不加。

## 4.3 一级栏目与内部导航的关系

我建议把导航分成两个层级。

**一级导航始终一致。**

它负责八个主要页面之间的切换。

**二级导航由每个栏目自己决定。**

例如：

项目页继续使用当前的 3D 场景热点和项目目录。

音乐页继续使用播放列表及相关控制。

番剧页继续使用观看状态和评分分类。

杂谈页继续保留搜索和文件夹。

笔记页继续保留 Quartz 原有的树状目录、搜索和反向链接。

这样就不需要将所有栏目强行改造成同一种标签组件。

一级导航提供整体统一性，二级导航保留各页面原来的使用习惯。

### 4.4 移动端

你已经实现了可拖拽的圆盘导航。

这个设计很有个人特色，我不建议删除。

但是视觉上可以重新设计。

目前它比较接近一个具有明显科技感的交互控件。

我希望它变成一个更轻盈的几何导航盘。

圆盘背景采用半透明纸张色，八个栏目沿圆周排列，当前栏目有清晰的颜色指示。

中心按钮使用与桌面导航一致的数学图形。

旋转时可以有轻微的弹性反馈。

同时保留正常点击、关闭和键盘交互，避免用户必须通过旋转才能导航。

**桌面端突出排版，移动端保留你已经具有的有趣交互。**

# 五、首页：我希望它最终长什么样？

当前的主要组件包括：

`ProfileCard`、`CloudPlayer`、`LyricBar`、`ThemeToggleBlock`、`PerformanceToggleBlock`、`PaperMonitor`、`SiteDashboard`。

我们不需要增加一堆新模块。

真正需要做的是让现有组件形成一张设计优秀的页面。

## 5.1 第一屏：个人身份与音乐

第一屏是整个网站最重要的视觉区域。

我建议采用非对称的开放式布局。

在 1440px 宽的桌面上，可以使用 12 列网格。

左边约 7 列，右边约 5 列。

### 左侧：个人身份

首先在顶部出现一个很小的栏目标识：

`PERSONAL JOURNAL / 00`

然后是较大的个人名称。

我希望这里不要继续使用传统的卡片式头像加名字。

可以采用一种更自由的编辑式排版。

例如名字占据较大的视觉空间，头像作为一个独立的图片元素，部分进入文字区域的留白。

你现在 `ProfileCard` 里的个人介绍可以原样保留。

只需要重新控制字重、换行和位置。

名字下方显示原有的个人简介。

再往下，是四项现有统计：

笔记、杂谈、音乐、番剧。

我建议它们采用类似出版物元信息的展示方式。

不再把四个数字都放进小型卡片。

最底部保留 GitHub、邮件、QQ 和微信入口。

这部分的重点是**排版本身形成视觉美感**。

### 右侧：音乐与数学图形

我希望保留 `CloudPlayer` 的全部功能。

但右侧不需要放置一个普通的圆角播放器卡片。

可以设计成一种更有表现力的音乐组件。

例如，专辑封面被放置在右侧中央，周围是由 Field Motif 生成的细线。

歌曲标题、艺术家、播放状态和控制按钮围绕封面进行排版。

专辑封面可以具有轻微的视差效果。

数学图形则在背后缓慢变化。

日间模式下，背景可以有非常柔和的天空色彩。

夜间模式下，背景呈现深蓝色。

这里不需要额外放置一个独立的数学实验窗口。

**让数学图形成为音乐播放器周围的视觉环境，页面会更加完整。**

### 第一屏最重要的视觉关系

我希望形成三个主要焦点：

1. 大字号的个人名称。
2. 右侧精致的音乐视觉。
3. 贯穿空白区域的数学线条。

其他信息成为辅助。

这样，首屏同时拥有现代前端的设计感、学术气质，以及音乐和二次元的个人特色。

它也不会像一个普通 Dashboard。

# 六、第二屏：主题与 TDA 论文周报

副标题继续使用原文。

底部保留日期和本期选读数量。

图片本身可以比较大，占据整个第二屏的主要视觉区域。

点击后展开的阅读窗口，则采用 Distill 风格的学术排版。

不要重新设计一个复杂的弹窗交互。

重点改进目录、标题、论文编号、正文宽度与阅读层次。

这样，访客会从第一屏比较轻松的音乐和个人介绍，自然进入更具有学术气质的内容。

**这正是我们希望形成的视觉节奏。**

# 八、其余七个栏目如何设计？

这里我建议采用一个重要原则：

**全站共享字体、颜色、导航、数学图形和交互规则，但每个栏目拥有不同的主视觉构图。**

| 栏目 | 设计方向           | 保留的特色                 |
| -- | -------------- | --------------------- |
| 项目 | 学术工作台 + 沉浸式 3D | 现有研究小屋、项目目录与交互热点      |
| 音乐 | 现代音乐产品 + 动态艺术  | 全局播放、歌单、歌词、粒子场        |
| 番剧 | 日系动画杂志         | Bangumi 收藏、观看状态、评分    |
| 杂谈 | 个人独立杂志         | 文章搜索、文件夹、瀑布流          |
| 笔记 | Distill 式数学出版物 | Quartz 知识库、公式、目录、反向链接 |
| 友链 | 创意社区目录         | 现有友链信息、头像、申请方式        |
| 关于 | 学术个人档案 + 生活表达  | 现有介绍、GitHub 活跃记录      |

下面分别说明。

## 8.1 项目页：保留研究小屋，重做界面层

这个页面应该继续保持与其他页面不同的视觉体验。

因为 3D 研究小屋已经是你的特色。

我建议主要修改三个部分。

**项目标题。** 采用更精致的编辑式排版，与全站字体系统一致。

**项目面板。** 将原来的信息弹窗改造成更接近学术作品档案的样式。项目标题、描述、技术信息和链接应该拥有清晰的层级。

**场景控制。** 保留旋转、热点、目录、静态回退等所有操作，统一按钮、图标和状态反馈。

不要把整个 3D 场景重新包装成大卡片。

也不要在这里增加第二个数学动画。

它本身已经足够有表现力。

## 8.2 音乐页：整个网站最自由的交互页面

我希望音乐页成为视觉表现最强烈的栏目之一。

保留你当前的音乐粒子场。

但是重新建立歌曲封面、歌词、播放控制和背景图形之间的视觉关系。

例如播放状态发生变化时，整个页面可以出现非常轻微的环境响应。

这里允许更多颜色、更多动效，以及少量的二次元插画元素。

不过，播放按钮、进度条和歌单始终应该是最容易操作的部分。

这也是我认为 Garden Eight 的交互方法最适合发挥作用的页面。

## 8.3 番剧页：日系动画杂志

我希望这个页面具有明显的二次元气息。

但不建议把所有动画封面都放入相同的毛玻璃卡片。

可以参考日本动漫杂志的版式。

封面保持较大的展示面积。

作品标题、评分、状态和其他元信息采用精致的排版。

已看与在看内容继续按照现有数据逻辑组织。

页面标题旁边可以加入非常轻微的插画元素。

这里要避免过多的光效与背景图案。

**动画作品本身已经具有丰富的色彩，网站的背景应该适当克制。**

## 8.4 杂谈页：个人独立杂志

你当前的瀑布流很适合杂谈。

我不建议改变它的内容结构。

可以着重调整图片大小、列间距、卡片边框、标题排版和悬停效果。

例如允许大图、小图和文字内容形成更自然的视觉节奏。

文章卡片可以更加接近杂志中的图文目录。

保留现有搜索功能。

这里可以比学术笔记页面更加轻松，也更有生活气息。

## 8.5 笔记页：Distill 是最直接的参考

这是唯一一个我建议明显降低装饰强度的主要栏目。

因为它承担真正的数学阅读任务。

我希望实现的是：

**一套具有 Distill 气质，但又保留你个人审美的数学笔记界面。**

具体来说：

正文采用清晰的衬线字体。

定理、定义和证明环境具有统一的视觉规则。

公式排版保持足够的空间。

目录、搜索、文件树和反向链接继续保留。

边注可以使用 Distill 式的窄栏结构。

插图和数学公式可以根据内容选择不同的页面宽度。

较复杂的图形允许适当突破正文区域。

但是绝大多数正文仍然保持安静。

颜色不需要完全复制 Distill。

可以继续使用你的网站主色，并融入少量淡紫色和暖白色。

我认为它应该成为整个网站学术气息最集中的地方。

## 8.6 友链页：有趣的创意社区

友链页面可以更加活泼一些。

但整体仍然使用统一的字体与网格。

建议保留头像、名称、描述与链接。

重新设计每个友链项目的展示形式。

例如把原来的大圆角卡片改成更简洁的图文组合。

悬停时，可以出现轻微的几何形变。

友链申请区域保留原功能。

这里适合表现 Garden Eight 式的交互趣味。

## 8.7 关于页：完整的个人档案

关于页可以比首页更加详细。

我建议采用学术个人档案与独立杂志相结合的排版。

原有 Markdown 内容无需改变。

主要调整标题、图片、段落与信息区域的布局。

GitHub 贡献图保留，但外观与新的字体、颜色和边框系统统一。

这里也可以保留更多个人照片和生活内容，让页面具有温度。

# 九、真正把八个栏目联系起来的交互

到这里我们需要考虑跨页面的连续性。

我认为应该重点设计三类交互。

## 9.1 导航连续性

导航栏本身始终存在。

当页面切换时：

当前标签的指示线移动。

栏目标题自然进入。

全局数学图形产生对应的变化。

页面内容通过轻微的透明度和位移过渡出现。

这可以在现有 Framer Motion 体系上实现。

不需要为了页面过渡重新引入复杂的前端框架。

## 9.2 视觉对象的连续性

假设首页有一组流线。

进入笔记时，这些流线逐渐淡化为标题附近的细线。

进入音乐页时，流线的形态变得更加明显。

进入项目页时，它们逐渐退场，把视觉空间交给 3D 研究小屋。

这里有一个重要原则：

**同一种数学视觉语言可以具有不同的存在强度。**

它无需在每个页面都占据主要视觉位置。

## 9.3 交互反馈的统一性

按钮、链接、卡片、弹窗和导航应该共享同一套基础动效规则。

例如：

| 交互类型   |       建议时长 |
| ------ | ---------: |
| 按钮悬停   |  150–200ms |
| 导航状态变化 |  250–350ms |
| 内容入场   |  300–450ms |
| 数学图形形变 |  500–900ms |
| 昼夜环境变化 | 800–1200ms |

这些时间只是初始设计参数，最终要通过实际演示调整。

对于内容阅读类页面，动画应更短、更克制。

对于音乐和项目页，可以允许更复杂的交互。

用户开启减少动态效果后，应保留静态视觉和全部操作功能。

# 十、怎样避免网站看起来单薄？

这是你之前提出的问题，我觉得需要明确回答。

我认为网站的厚度来自三个方面。

**第一，导航提供完整的内容结构。**

八个一级栏目已经足够丰富。

我们没有必要把所有内容都塞进首页。

**第二，不同栏目具有各自的视觉深度。**

进入音乐馆，用户看到完整的音乐体验。

进入研究小屋，用户能够探索 3D 场景。

进入笔记，用户能够阅读一套完整的数学知识库。

进入番剧，用户能够浏览动画收藏与评价。

这些内容本身就足以让网站具有深度。

**第三，统一的设计系统让这些体验属于同一个世界。**

访客在任何页面都能看到相同的字体体系、导航风格、几何语言和交互规律。

这会让网站具有完整性。

对于首页，我尤其不希望它成为一个很长的营销 Landing Page。

你不是在向用户推销某种服务。

首页的任务是表达个人身份，并让人自然进入你的数字世界。

因此，保留现在的内容结构、提高每一部分的视觉质量，是我认为更合理的方案。

# 十一、具体技术实施方案

我建议沿用现有 Next.js、React、Tailwind 和 Framer Motion 技术体系。

不要为这次改造更换框架。

需要新增的是设计层，而非重新开发业务逻辑。

| 层次   | 主要改造对象                                              | 目标               |
| ---- | --------------------------------------------------- | ---------------- |
| 全局样式 | `globals.css`                                       | 字体、颜色、间距、表面材质    |
| 导航   | `Navbar.tsx`                                        | 新的标签视觉、选中状态、交互反馈 |
| 首页布局 | `app/page.tsx`                                      | 非对称编辑式布局         |
| 个人介绍 | `ProfileCard.tsx`                                   | 开放式排版            |
| 音乐组件 | `CloudPlayer.tsx`、`LyricBar.tsx`                    | 与首页数学视觉融合        |
| 主题组件 | `ThemeToggleBlock.tsx`、`PerformanceToggleBlock.tsx` | 日系插画与数学交互        |
| 论文周报 | `PaperMonitor.tsx`                                  | 学术杂志式封面与阅读界面     |
| 背景系统 | `FieldScene.tsx`、`spectralField.ts`                 | 全站数学视觉语言         |
| 各栏目  | 对应页面组件与 CSS                                         | 统一视觉、保留原有逻辑      |

我建议特别注意 `FieldScene` 的性能。

因为你已经同时使用了背景动画、谱场、音乐粒子和独立的 3D 场景。

改造时应优先复用现有数学计算和渲染机制。

不能让新视觉系统导致重复渲染或多个动画循环互相竞争。

## 实施顺序

**第一阶段：视觉设计系统**

确定字体、颜色、背景、网格、组件风格和几何母题。

产出一套完整的静态设计规范。

**第二阶段：首页视觉**

按照现有组件制作桌面端和移动端设计。

首先验证静态构图。

然后逐步加入数学图形和交互。

**第三阶段：导航与全站框架**

实现新的顶部导航、移动端导航、页面过渡和统一状态反馈。

**第四阶段：内页视觉统一**

优先处理笔记、项目和音乐。

这三个页面分别承担学术、交互和艺术表现，是网站的核心。

之后处理番剧、杂谈、友链和关于。

**第五阶段：数学交互与整体打磨**

将经过验证的谱场视觉语言应用到各个页面。

最后检查性能、响应式布局、动画节奏和阅读体验。

这里必须坚持一个原则：

**每一阶段都用真实页面截图与设计稿对照，而不是以代码能正常运行作为设计完成的标准。**

# 十二、最终的首页应该呈现什么？

我把整个方案浓缩成一个明确的页面结构。

| 页面区域  | 现有组件                        | 新的视觉角色             |
| ----- | --------------------------- | ------------------ |
| 顶部    | Navbar                      | 学术出版物式导航 + 数学交互    |
| 第一屏左侧 | ProfileCard                 | 大字号个人介绍、头像、统计、社交入口 |
| 第一屏右侧 | CloudPlayer                 | 音乐与数学流线构成的交互视觉     |
| 第一屏底部 | LyricBar                    | 精致的歌词信息带           |
| 第二屏左侧 | 两个模式切换组件                    | 日系光影插画 + 数学模式展示    |
| 第二屏右侧 | PaperMonitor                | 学术杂志式 TDA 周报       |
| 页面结尾  | SiteDashboard               | 出版说明式网站状态区域        |
| 全局背景  | BackgroundSlider、FieldScene | 统一的数学与动画氛围         |

整个首页不需要额外增加内容。

我们真正要做的是把这些已经存在的东西重新编排，形成一个有节奏、有重点、有个性的视觉作品。

# 十三、我对最终设计的判断

这套方案有三个必须守住的重点。

**第一，Distill 的统一性。**

你的每个页面都应该能清楚看出属于同一套设计系统。

特别是学术排版、字体和阅读体验，必须达到足够高的完成度。

**第二，Garden Eight 的交互质量。**

动效需要自然、连续、有趣。

它们应该与用户的操作和页面内容建立联系。

但不能让整个网站变成一个难以操作的实验作品。

**第三，数学真正参与视觉设计。**

我们已经有一个不错的起点：现有的谱场系统。

应该在这套系统上进一步发展生成式视觉语言，而不是重新堆砌一些复杂的数学名词。

至于二次元，我希望它像一种持续存在的情绪。

在首页，它是柔和的光影与插画。

在音乐页，它可以更加鲜明。

在番剧页，它成为主要的视觉内容。

在数学笔记中，它退到背景，只留下颜色和少量设计细节。

这样的网站应该既有学术出版物的严谨，又有日本创意工作室的趣味性。

## 最终建议

我建议将这次改造定义为：

**Nothing New Visual Renewal — 一套由数学驱动、以编辑式设计为基础的个人网站视觉更新。**

保留现有品牌「阿の宝藏之地」和全部八个栏目。

首页不再强调大量玻璃卡片，而是以个人介绍、音乐、数学图形和 TDA 周报组成具有视觉节奏的开放式布局。

导航保持完整，使用连续的数学形变与精致的状态反馈建立跨页面联系。

各个栏目保留既有功能，同时通过统一的字体、颜色、排版与几何系统形成整体。

我认为这已经是一套可以进入实际视觉设计的方案。

**但现在还不能直接写代码。**

下一步应该针对这套方案制作四张关键视觉设计稿：**桌面端首页、移动端首页、全局导航展开状态，以及一张具有代表性的数学笔记页面。**

其中最需要先验证的是桌面端首页。

如果它不能在静态状态下同时体现 Distill 的精致、Garden Eight 的艺术表现和你个人的二次元气质，那么这套方案还需要继续调整。
