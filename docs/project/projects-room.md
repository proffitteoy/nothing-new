# 窗边研究小屋

## 首页实体空间修正（2026-11-24）

首页从第一帧起由同一场景里的实体窗墙、窗洞、山岸和反射水面渲染，不再在起步时从整屏贴图切换到三维。后墙落在原侧墙末端 `z=1.85`，保留原模型坐标、原地板和项目机位；18cm 窗洞与 12cm 窗台沿用原浅木照片作材质，窗框不随进度淡出。转身改为一段连续旋转，画布宽度不再随进度变化。实现细节及物理近似边界见[首页实体窗墙与反射水面](home-scene.md#首页实体窗墙与反射水面2026-11-24)。

几何测试覆盖整个往返路径中的对象稳定、窗墙深度写入、水面水平、岸线衔接及相机碰撞；相机测试检查旧转向分段处不再停顿。浏览器回归继续覆盖同一画布、原项目取景、详情、输入保护、历史恢复、减少动态与失败回退。

开场以 `c966422` 的浅木大窗首页为基线，恢复完整原室内照片、湖景取景、侧栏与音乐。撤销 #118 用自制超广角窗前取景替换首页的做法。项目页继续使用原宽／窄桌面机位、47° FOV 和 0.05/35 裁剪面；中段及自由查看的远裁剪设为 700，保留窗外远景。

## 首页与项目页连接（2026-11-18）

以 `main@7ac92f2` 为基线，接入窗前／房间／湖景状态与既有素材显示切换。房间 GLB、默认镜头、原图片及材质沿用 main；不进行房间几何重建或同一三维空间内的连续镜头转场。

桌面使用 `5H` 原生轨道：首页窗前在 `2H`（进度 0），项目房间在 0（进度 -1），湖景状态在 `4H`（进度 +1）。滚动端点使用 replace 更新语义路由，普通链接保持正常导航；返回、前进、刷新及 resize 恢复归一化检查点。主动开启右下角「自由查看」后暂停轨道、允许缩放；结束或 Esc 先沿用原相机复位，再经返回状态回到窗前。详情打开时 Esc 优先关闭详情，返程可由新的滚动输入取消。

导航预览、论文窗口、项目详情、目录和自由查看期间暂停轨道滚动；播放器操作不推进轨道。页面共享原根级 MusicProvider/audio，场景仍分别加载与释放。模型失败时原静态图和六项目录保留。手机、平板继续使用 main 的点击导航及项目触控规则。桌面按与首页一致的设备判定启用，不再限制窗口尺寸或减少动态设置；减少动态仍保留原静态首页及相机减动规则。窄于 768px 的桌面预览也显式使用内部滚动容器，离开这两个页面后恢复原滚动样式。

## 全站接入与资源生命周期

- 标题继承站内宋体，背景、导航、圆角半透明阅读面板和悬浮播放器延续现有样式。
- 外观固定使用 GLB 内嵌窗光贴图；音乐只使用 `MusicProvider`，没有第二套音频播放实例。
- 沿用桌面 `app-scroll-root` 与移动端文档滚动，不在 window 上接管滚轮。
- 3D 就绪时设置临时 `data-project-room-active`；Field 保留后景，前景粒子与交互波纹停止绘制，静态浏览或离开页面立即恢复。
- Three.js 与 GLTFLoader 在客户端边界加载，使用 three-mesh-bvh 建立拾取索引。静止时停止场景 RAF，页面后台暂停；卸载释放几何、材质、纹理、监听器和 WebGL renderer。
- React Strict Mode 会复用 canvas，只有 canvas 实际脱离文档后才强制释放 context，避免旧实例的异步 context-loss 事件杀死替代实例。
- GLB 请求有 20 秒超时，可切静态或重试；context loss 进入同一可读降级状态。

脚本生成真实尺度工作间、完整家具背面、九个交互物件及对应 `anchor_*`。统一 UV 后在 Cycles 中分别烘焙日间窗光与夜间台灯的直接光、间接光、表面色及屏幕自发光，离线降噪后导出 GLB 和夜间 JPG，随后用同一个场景渲染日间、夜间、详情及手机日夜构图；最后一条命令编码为 WebP。第一条命令以 SVG/Sharp 重建原创屏幕、键帽字印和书脊，不请求外部素材。每次重建后运行资产测试，保证 React 目录与模型命名没有漂移。

交互按组保留，日夜各用一张 4096² 图集：左上角保留经 OpenImageDenoise 离线降噪的 3072² 房间光照；右侧和底部保留高分辨率屏幕、键帽字印与书脊。印刷表面乘以烘焙的局部光照，LCD 保留自发光；小键帽合并同一键盘的光照采样，并为顶面、斜裙和侧面保留稳定色阶，避免亚像素 UV 岛形成脏色块；文字区域不经过降噪，以免被抹成色块。所有物件仍使用同一张图集和无光照材质，不增加运行时字体或屏幕绘制。GLB 内嵌日间贴图并声明 `KHR_materials_unlit`，夜间图由同一路由资源单独加载；Three.js 直接显示烘焙结果，避免重复照明。默认视角与预览图使用相同表面与近似相机参数。运行时没有实时阴影或后处理。无光照模型导出时省去不用的法线属性，Blender 源文件保留材质与建模法线。图集边长由 3072 增至 4096，GPU 纹理占用因此增加；下载体积、三角形与 draw call 预算继续由资产测试约束。

仅压缩源文件由 `preloadRoomAssets` 在标签页内复用；场景挂载后解析模型、解码贴图，并为各组建立局部坐标的静态 BVH。每次投影或点击只变换射线，保持物件微动后的命中与遮挡正确；挂载后的模型、贴图、BVH、ImageBitmap 和监听器随路由卸载释放。2026-11-12 已删除无调用者的 CPU 预解析/60 秒待用缓存；启动阶段不再承诺预先解析模型。历史加载测量见 [全站启动与导航](site-startup.md)。

资产测试将 **GLB 与夜间贴图之和**限制在 4 MiB 内，全部几何少于 100k 三角形、primitive 少于 80；这些是资源规模检查，不等于网络或帧率验收。
