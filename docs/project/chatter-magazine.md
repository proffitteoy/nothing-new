## 设计依据与参考

本地两份方案共同作为依据：

- [原始视觉方案](<./frontend refactoring.md>)：统一字体与色彩、开放式排版；§8.4 明确保留搜索、文件夹和瀑布流，改进图片大小、列距、标题与悬停。
- `docs/project/interaction research.md`：界面与画面的主次、克制的外围操作、视觉优先于工程回归。原稿保持本地未跟踪，不随本任务上传。首页特有的中心人物、日月、边缘音乐与五分钟周期不复制到杂谈。
- **2026-11-05 用户补充优先于旧候选色板：任何界面位置不得出现米黄色。** 保留原有原画背景，不新增白色、米黄色或其他整页纯色遮挡层；仅需实色表面的局部控件采用中性白。原画和文章封面不重新调色。

实际打开并检查的杂志参考（最终只做电脑端）：

| 参考                                                            | 借鉴的方法                                       | 本页实现                                                                           |
| --------------------------------------------------------------- | ------------------------------------------------ | ---------------------------------------------------------------------------------- |

## 实现范围

- `ChatterBoard` 与局部 CSS Module：紧凑刊头、下划线搜索、封面左下角的完整标题。三列在不同起点独立向下堆叠，左右主图高于中间主图，不强求行或列底部对齐。本轮按用户要求只做电脑端；手机保留已有响应式安全样式，不再调试或宣称完成手机验收。
- 响应式列数由媒体查询订阅决定；按原数组连续分段，跨断点和搜索后的 DOM 顺序仍与原数据一致，不做随机重排。封面与标题共同决定最小高度，长标题可以自然撑高卡片。
- 搜索仍对标题执行 `trim().toLocaleLowerCase("zh-CN")` 后的子串匹配。结果数量用 live region 播报，空结果提供清空恢复，搜索和卡片均可键盘操作。
- 文章、目录、混排顺序、封面 URL 和路由不变。文件夹保留角标和记录数量，标题不截断；连续英文可换行。
- 封面继续复用原图片预算、近视口加载和外站 referrer policy。根据版面放大／裁切封面，而非将所有图固定成同一高度；图片使用 `object-fit: cover`，来源与文件不变。未加载、失败或缺失时，保留空间与可点击标题。
- 标题位于左下角，底部局部渐暗提供对比度；不对整张图片套统一灰色蒙层，不截断标题。长标题可以撑高图版，不以截断标题换取整齐的行高。
- 悬停仅轻微缩放封面、显现并移动箭头；保留焦点框和减少动态效果。列表搜索直接更新，避免原布局动画跨列覆盖。
- 因用户禁用米黄色，同步将现有共享导航和周报的日间表面 Token 改为中性白；只改色值，不改这些组件的布局或业务。

## 独立预览与复现

检出本分支，使用 Node 22 与 npm 10+：

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd run start -- --hostname 127.0.0.1 --port 3155
```

访问 <http://127.0.0.1:3155/chatter>。本地无需生产凭据；音乐、动漫等第三方服务仍受本地配置和网络影响。远程预览状态以 PR Checks 为准。

可选 Python Playwright 依赖：

```powershell
python -m venv .sync/tmp-chatter-tools
.\.sync\tmp-chatter-tools\Scripts\Activate.ps1
python -m pip install playwright
python -m playwright install chromium
npm.cmd run test:chatter
```

也可用已有 Chrome：

```powershell
npm.cmd run test:chatter -- --browser "C:/Program Files/Google/Chrome/Application/chrome.exe"
```

脚本连接已启动的服务；`--url` 可指定其他端口或 PR 预览，`--output` 可指定截图目录，默认写入 Git 忽略的 `.sync/tmp-chatter-55/desktop/`。不改文章和目录；长标题压力用例仅临时改浏览器 DOM，图片失败用例仅在独立标签页拦截请求。
